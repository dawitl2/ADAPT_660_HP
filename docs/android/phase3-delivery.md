# ADAPT Control 0.3.0

**A native headset control experience for Android.**

This release brings together Home, Actions, Device, Settings, AI Voice, Voice Notes, Study Companion and a concise welcome screen. The interface uses headset photography, a horizontal battery indicator, inset settings groups, segmented noise controls and Light / Dark / System appearance.

**Purple button:** configurable short, double and long press actions, with protected pairing / recovery.

**Voice:** Gemini Live and Android system-assistant provider paths, session status, transcripts and audio interruption handling.

**Notes and study:** private local files, audio playback, editable notes, spoken learning modes, structured feedback and session history.

**Automation:** phone utilities, a certificate-pinned HTTPS PC companion and combined action outcomes.

**Persistence:** DataStore preferences, a private JSON / WAV library and Keystore-protected credentials.
