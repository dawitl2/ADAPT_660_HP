# Standing project order

Hardware → replaceable HAL/firmware → transport-independent commands → ADAPT Control
(Kotlin/Compose on Samsung Galaxy S20+) → AI/phone/PC actions.

Purple button: short → assistant, double → voice note, long → study companion;
protected very long → pairing. Timing/normal mappings are configurable. Recovery
must retain an independent path. No unverified flashing, vendor commands, signature
bypass or interrupted-update experiments.

**CONFIRMED**: cited source or reproducible observation. **ASSUMED**: provisional
software choice/hypothesis. **UNKNOWN**: evidence absent. Host tests confirm host
behavior only. Keep secrets, vendor firmware and private captures out of Git.
Small coherent commits; validate/diff-review; push each phase without squash/force.
Execute only the phase supplied by the user.
