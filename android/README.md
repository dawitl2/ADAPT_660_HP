# ADAPT Control

**Voice. Ideas. Focus. One button.**

Native **Kotlin + Jetpack Compose** for Android 10+, built around the **Samsung Galaxy S20+** and **ADAPT 660**.

**Screens:** Home, Actions, Device, Settings, AI Voice, Voice Notes, Study Companion and Welcome.

**Storage:** private local files, DataStore preferences and Keystore-protected pairing credentials.

## Build

```powershell
./gradlew.bat assembleDebug
```

**APK:** `app/build/outputs/apk/debug/app-debug.apk`.
